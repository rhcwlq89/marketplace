== 개요

본 문서는 Marketplace API의 REST 엔드포인트 명세입니다. 모든 스니펫은 **통과한 컨트롤러 테스트**에서 자동 생성되었으므로, 실제 동작과 동기화됩니다.

* Base URL: `/api/v1`
* 인증: JWT Bearer 토큰 (`Authorization: Bearer <accessToken>`)
* 응답 포맷: `{ code, message, data }` (`CommonResponse<T>`)
